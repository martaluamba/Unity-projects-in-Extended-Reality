# Unity-projects-in-Extended-Reality
This repository is about the some labs and the final project of the course Extended Reality in Theory and in Practice at KTH (Royal Institue of Technology). The project is about creating a multimodal interaction in Virtual Reality using Unity version 6000.2.14f1, XRI Interaction Toolkit and ML-Agents.

# The Mini Project: 
This Unity project demonstrates three levels with different interaction modalities in virtual reality:

1. **Passive Level:**  
   - The user observes and follows the ML agent.

2. **Multimodal Level:**  
   - The system provides feedback using colors and sounds:  
     - **Red + "Oh no"** → the agent is far from the cube  
     - **Green + "Congratulations"** → the agent is close to the cube

3. **Active Level:**  
   - The user can directly interact with the agent by moving the cube in the VR environment.

## Features
- XR interaction and immersive environment  
- Pre-trained Unity ML-Agents model for agent behavior  
- Audio feedback integrated for guidance
